---

## 🚨 Reporting a Vulnerability

The Jeevan Setu team takes security, emergency telemetry privacy, and infrastructure resilience seriously.

If you discover a security vulnerability or critical failure mode affecting offline disaster dispatch, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Email the maintainers directly or use GitHub's private vulnerability reporting feature.
3. Include detailed reproduction steps and affected coordinates/APIs.

We aim to acknowledge reports within **24 hours** and release security advisories promptly.
